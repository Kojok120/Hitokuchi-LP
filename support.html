サポート

こんにちは。ひとくちをご利用いただき、ありがとうございます。ここでは、よくある質問と、お困りのときの連絡先をご案内しています。

よくある質問

サブスクリプションは本当にないの？

はい、すべて一回きりの買い切りです。毎月の支払いは発生しません。

広告は将来追加されますか？

永久にありません。「広告なし」はアプリの設計思想です。

データは送信されますか？

いいえ。HealthKit への書き込み以外、外部通信は一切行いません。記録データはあなたのデバイスから出ません。

機内モードでも使えますか？

はい、完全にオフラインで動作します。ネットワーク接続は不要です。

VoiceOver なしでも使えますか？

はい。VoiceOver First 設計ですが、視覚ユーザーにとってもシンプルで迷わない UI になっています。

水分係数の根拠は？

文部科学省『日本食品標準成分表』に準拠しています。煎茶 0.99、玉露 0.95、味噌汁 0.90、コーヒー 0.85 など、飲み物ごとに個別に設定しています。

医療アドバイスとして使えますか？

いいえ、医療機器ではありません。毎日の「気づき」をそっと後押しするアプリです。健康に関する判断は、かかりつけの医師にご相談ください。

今後も無料でアップデートされますか？

v1 系のバグ修正・iOS 互換性アップデートは継続します。v2 以降の大幅な新機能は別売 IAP となる可能性があり、その際は事前にお知らせします。

バンドルと個別、どう選べばいいですか？

全部入りバンドル $3.99 には、5 種のテーマと 2 種のボイスパックがすべて含まれます。個別購入は各 $0.99 で、気に入ったものだけを選べます。全部揃えたい場合はバンドルのほうがお得です（個別で全 7 点は $6.93）。正確な価格は App Store の表示をご確認ください。

アプリ本体は無料ですか？

はい。ダウンロードと基本機能（記録・通知・標準語メッセージ・デフォルトテーマ）はすべて無料でご利用いただけます。テーマとボイスパックは、必要な人が必要な分だけ購入できる仕組みです。

デバイスを機種変更したら購入履歴はどうなりますか？

同じ Apple ID でサインインしていれば、設定画面の「購入を復元」から過去の購入を復元できます。Family Sharing にも対応しています。

お問い合わせ

FAQ で解決しない場合は、以下の方法でお気軽にご連絡ください。

  • メール: kojokamo120@gmail.com
  • GitHub Issues: github.com/Kojok120/Hitokuchi/issues

返信について: 原則として 2〜7 日以内 にご返信します。個人運営のため、お時間をいただく場合がございますが、必ずお返事いたします。

バグ報告のお願い

不具合を見つけた場合は、以下の情報を添えてご連絡いただけると、素早い対応につながります。

  1. iOS のバージョン（例: iOS 18.3）
  2. 端末の機種（例: iPhone 15 Pro）
  3. ひとくちのバージョン（設定 → このアプリについて で確認できます）
  4. 発生手順（どの画面で何をしたら、どうなったか）
  5. できればスクリーンショットや短い画面録画

ご協力ありがとうございます。いただいた情報は品質向上のためだけに使用し、第三者には共有しません。

購入・返金について

アプリ内課金（テーマ・ボイスパック・バンドル）は Apple の決済システムを通じて処理されます。購入後のご返金をご希望の場合は、開発者ではなく Apple へ直接ご申請ください。

  • Apple 返金申請: reportaproblem.apple.com
  • Apple のサポート: support.apple.com/billing

「購入したのにコンテンツが反映されない」「決済が二重に発生した」といった技術的な問題については、上記のメールアドレスまでご相談ください。

プライバシーに関するお問い合わせ

プライバシーに関するご質問・ご要望（データに関する開示・削除のご依頼等）は、kojokamo120@gmail.com まで件名に「プライバシー」とお書き添えのうえご連絡ください。詳細は プライバシーポリシー をご覧ください。

機能リクエスト

「こんな機能があったら嬉しい」というご要望も歓迎しています。GitHub Issues もしくはメールでお気軽にお寄せください。すべてのご要望に対応できるとは限りませんが、ひとつひとつ丁寧に拝見しています。

Bug Reports

When reporting a bug, the following information helps us fix it quickly:

  1. iOS version (e.g., iOS 18.3)
  2. Device model (e.g., iPhone 15 Pro)
  3. Hitokuchi version (see Settings → About)
  4. Steps to reproduce (what you did, what happened, what you expected)
  5. Screenshots or a short screen recording if possible
